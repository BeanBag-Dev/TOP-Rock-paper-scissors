Project plan:

1. Setup the initial HTML file and javascript files
2. Create 3 buttons, Rock, Paper, Scissors
3. When a player presses one button, it will submit their choice
4. Compute a random choice for the computer
5. Compare the choices
    - If both picked the same, it's a draw
    - If one picked rock at the other paper, paper wins
    - If one picked scissors and the other paper, scissors wins
    - If one picked rock and the other picked scissors, rock wins
6. Display who won or if there was a draw in text on the webpage: "Player: [Choice], Computer [Choice] - X wins! (or draw)"
